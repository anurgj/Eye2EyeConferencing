# zoom-instant-sdk-web-1.0.3

This sample project uses the zoom video SDK, please also find the detail here: https://marketplace.zoom.us/docs/sdk/video/web/build/sample-app

To start the project, please also read the README file in the Sample folder to run the project

Currently I adjust the layout only at runtime, after you join a meeting room, please press F12 to open browser development tool.

In elements, please find the video container inside div class = "video-container" (should be under div clss = "App")

you could drag video-container above share-container to change left or right (based on how you want the participant to be placed at right or left)

inside Styles, find .viewport .video-container, you can change from width:100% up to 500% (or adjust based on the browser resolution)
